# Garimpo Scanner Android

Aplicativo de teste que abre páginas públicas 99Food no próprio aparelho Android, extrai nomes/preços visíveis no WebView e envia somente esses dados para o backend Garimpo Food.

## Teste rápido

1. Instale o APK debug.
2. Abra o app.
3. Aguarde a página 99Food carregar.
4. Role o menu se necessário.
5. Toque em **Escanear página**.
6. Quando aparecer a confirmação, toque em **Ver Garimpo**.
7. No Garimpo Food, toque em **Atualizar**.

A V1 não faz pedidos, não coleta senha e não tenta contornar autenticação ou captcha.

Build automático habilitado via GitHub Actions.
